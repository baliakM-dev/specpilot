# AI Review Checklist

A checklist reviewers should apply when evaluating AI-generated requirement analysis before approving, rejecting, or returning it for changes (e.g. does the summary match the original requirement text, are acceptance criteria testable, does the API proposal follow existing conventions, are risks realistic).

**Status:** not yet implemented. To be completed in Phase 14/15 (Review workflow) of [`TASKS.md`](../../TASKS.md), once the review UI and process are built and there's real AI output to evaluate against.
